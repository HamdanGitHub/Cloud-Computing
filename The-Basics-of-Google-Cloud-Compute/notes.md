# Challenge Notes

## Objective

Build the infrastructure for a simple web application using Google Cloud services.

## Tasks Completed

- Created a Cloud Storage bucket using the project ID.
- Created a Compute Engine virtual machine.
- Created and attached a 200 GB persistent disk.
- Installed and started the NGINX web server.
- Verified that the NGINX service was running.
- Confirmed that all challenge tasks were completed successfully.

## Key Learning Points

- Cloud Storage buckets are used to store application files.
- Compute Engine provides virtual machines for hosting applications.
- Persistent Disks provide durable block storage for VMs.
- NGINX can be installed on a Linux VM to host web applications.
- Cloud Shell allows resources to be managed using the `gcloud` CLI.
