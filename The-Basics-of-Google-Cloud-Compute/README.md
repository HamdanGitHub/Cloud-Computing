# The Basics of Google Cloud Compute - Challenge Lab

## Overview

This challenge lab is part of the **Google Cloud Computing Foundations Certificate** on Google Cloud Skills Boost.

Unlike guided labs, this challenge required me to apply the knowledge learned throughout the course without step-by-step instructions. I successfully completed all required tasks and earned the **The Basics of Google Cloud Compute** Skill Badge.

---

## Challenge Tasks

- Create a Cloud Storage bucket.
- Create a Compute Engine virtual machine.
- Create and attach a persistent disk.
- Install and configure an NGINX web server.
- Verify the web server deployment.
