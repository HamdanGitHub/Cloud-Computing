# Google Cloud Computing Foundations: Cloud Computing Fundamentals

## Overview

This course introduces the basic concepts of cloud computing and explains how Google Cloud provides computing, storage, networking, and application services through the internet.

---

## What is Cloud Computing?

Cloud computing is the delivery of computing resources such as servers, storage, databases, networking, and software over the internet. Instead of purchasing and maintaining physical hardware, users can access resources on demand and pay only for what they use.

### Benefits of Cloud Computing

- Pay-as-you-go pricing
- Easy to scale resources up or down
- High availability and reliability
- Global infrastructure
- Improved security and compliance
- Faster application deployment

---

## Cloud Service Models

### Infrastructure as a Service (IaaS)

Provides virtual machines, storage, and networking infrastructure.

Examples:
- Google Compute Engine
- Amazon EC2
- Microsoft Azure Virtual Machines

---

### Platform as a Service (PaaS)

Provides a platform for developing and deploying applications without managing servers.

Examples:
- Google App Engine
- Google Cloud Run

---

### Software as a Service (SaaS)

Provides software applications through a web browser.

Examples:
- Gmail
- Google Docs
- Google Drive

---

## Cloud Deployment Models

- Public Cloud
- Private Cloud
- Hybrid Cloud
- Multi-Cloud

Google Cloud is primarily a public cloud provider but also supports hybrid and multi-cloud solutions.

## Google Cloud Global Infrastructure

Google Cloud operates worldwide using:

- Regions
- Zones
- Data Centers

### Region

A geographical area containing multiple zones.

Example:

- us-central1
- asia-southeast1
- europe-west1

---

### Zone

A deployment area within a region.

Example:

- us-central1-a
- us-central1-b

Using multiple zones improves availability and fault tolerance.

## Identity and Access Management (IAM)

IAM controls who can access Google Cloud resources.

Important concepts:

- Principal (user, group, or service account)
- Role
- Permission

Common roles include:

- Viewer
- Editor
- Owner

Following the Principle of Least Privilege helps improve security.

## Billing

Google Cloud uses a pay-as-you-go pricing model.

Many services qualify for the Free Tier, making it easier to learn and experiment.

---

## Cloud Shell

Cloud Shell is a browser-based Linux terminal with the Google Cloud CLI already installed.

Benefits:

- No installation required
- Secure access
- Includes Git and development tools

---

## Cloud Console

The Google Cloud Console is a web interface used to create and manage cloud resources.

It allows users to:

- Create virtual machines
- Manage storage buckets
- Configure networking
- Monitor projects
