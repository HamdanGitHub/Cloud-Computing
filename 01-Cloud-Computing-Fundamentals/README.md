# Google Cloud Computing Foundations: Cloud Computing Fundamentals

## Overview

This module is part of the **Google Cloud Computing Foundations Certificate** offered through **Google Cloud Skills Boost**.

The course introduces the fundamentals of cloud computing and provides hands-on experience with core Google Cloud services through practical labs.

---

## Learning Objectives

By completing this module, I learned how to:

- Understand cloud computing concepts and benefits.
- Differentiate between IaaS, PaaS, and SaaS.
- Explore Google Cloud's global infrastructure (Regions and Zones).
- Use Google Cloud Console and Cloud Shell.
- Create and manage Cloud Storage buckets.
- Create and manage Compute Engine virtual machines.
- Attach and use Persistent Disks.
- Deploy applications using App Engine.
- Deploy Cloud Functions.
- Deploy containerized applications with Google Kubernetes Engine (GKE).
- Install and configure an NGINX web server.
