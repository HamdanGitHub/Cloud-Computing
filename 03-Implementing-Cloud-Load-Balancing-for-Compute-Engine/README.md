# ☁️ Project 03 – Implementing Cloud Load Balancing for Compute Engine

## Overview

This project demonstrates how to deploy and configure both Network Load Balancers and HTTP Load Balancers using Google Compute Engine.

The challenge included creating multiple web server virtual machines, configuring firewall rules, deploying Managed Instance Groups (MIGs), configuring backend services, health checks, and validating traffic distribution through Google Cloud Load Balancing.

---

## Objectives

- Create multiple Compute Engine VM instances
- Install Apache Web Server
- Configure firewall rules
- Configure Network Load Balancer
- Configure HTTP Load Balancer
- Create Managed Instance Groups
- Configure Backend Services
- Configure Health Checks
- Verify backend health
- Test load balancing functionality

---

## Google Cloud Services Used

- Compute Engine
- Virtual Private Cloud (VPC)
- Firewall Rules
- Network Load Balancer
- HTTP Load Balancer
- Backend Services
- Managed Instance Groups
- Instance Templates
- Health Checks
- URL Maps
